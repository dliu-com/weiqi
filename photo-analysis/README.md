# Quick board-photo analysis

This standalone feature is distributed under AGPL-3.0-only. Its server-side board recognition is a Python port of Kaya board-recognition code (AGPL-3.0, kept for reference in `vendor/kaya`). Photo recognition runs in a bounded private Lambda through the site's protected API. The browser compresses and uploads a photo, receives an automatically detected board, and discards the photo. No corner marking is required. A single photo cannot infer earlier moves or captures. Photos, positions and AI results are not saved in the cloud. Requests store only a UUID/hash and a short-lived quota/concurrency counter.

The page itself is plain ES modules with no bundler: `src/photo.html`, `photo.css`, `analysis.js`, `analysis-position.js` and `position-api.js`, reusing the site's shared board, SGF, navigation, language and style files. `node scripts/build-photo-analysis.mjs` (or `make build-local-analysis`) writes the licence notices and the corresponding-source download into the ignored `src/photo-assets/`. Model sources and exact revisions are in SOURCES.json. Private test photos are never part of the build or source download.

The source download offered by the page contains this directory's licences and notes, the page/script/style files and shared site files, the build script, the server detector and lightweight KataGo worker in `backend/position/`, and the API handler. Upstream checkpoint and training-source links are offered alongside the Moku model.

Modified standalone integration: 8 October 2026. This feature is provided without warranty; copying and redistribution are permitted under the included AGPL-3.0 license. The surrounding project's existing files retain their existing terms.

The `/analysis` page also accepts a local SGF or a hand set-up and allows playing or navigating one sequence. Playing from an earlier position replaces the later moves. It stores only the current game as SGF, the selected position, side to move and editing mode in localStorage; it never stores photos or analysis results. AI analysis is cloud only (128-visit native KataGo with a pinned small model): each Analyse press, and each move played afterwards, sends one short request with the position and available move history. There are no long-running or background jobs.
